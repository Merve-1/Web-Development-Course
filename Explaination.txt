Hierarchy order is important in SEO

Heading Hierarchy (H1 → H6)
This is the most important on-page hierarchy.

Example structure:
H1 – Main topic of the page (use once)
H2 – Major sections
H3 – Subsections under H2
H4–H6 – Deeper details if needed

Example:
H1: Best SEO Strategies for 2026
H2: On-Page SEO
H3: Keyword Optimization
H3: Internal Linking
H2: Technical SEO
H3: Page Speed
H3: Mobile Optimization

Why it matters:
Helps search engines understand topic importance
Improves content readability
Supports featured snippets

====================================
Formatting
- Bold (<b>) – Displays text in bold style to visually highlight it without adding semantic importance.
- Emphasize (<em>) – Emphasizes text to show stress or importance, usually displayed in italics.
- Italic (<i>) – Displays text in italic style for alternate voice, technical terms, or stylistic purposes.
- Strong (<strong>) – Indicates text with strong importance, usually shown in bold and meaningful for accessibility/SEO.
- Insert (<ins>) – Shows text that has been added or inserted into a document (often underlined).
- Delete (<del>) – Indicates text that has been removed from the document (usually shown with a strikethrough).
- Sub (<sub>) – Displays text as subscript, slightly below the normal text line (e.g., chemical formulas like H₂O).
- Sup (<sup>) – Displays text as superscript, slightly above the normal text line (e.g., exponents like x²).
- Mark (<mark>) – Highlights text to show it is relevant or marked for reference.
- Underline (<u>) – Underlines text for stylistic emphasis or to indicate non-textual annotation.

====================================
Division Tag (div)
A <div> acts like a box that holds other HTML elements so you can style or organize them as one unit.

====================================
Semantic Tags 
HTML elements that describe the meaning of the content they hold. By reading the tag name, you can understand the role of that section on the webpage.

- <header> – page or section header
- <nav> – navigation links
- <section> – a section of content
- <article> – independent content
- <footer> – page footer

These tags are part of HTML5 and help both developers and search engines understand the structure of a webpage.

====================================
ID and Class in HTML

ID (id)
- An ID is a unique identifier for a single HTML element.
- Each ID should appear only once on a page.
- Often used for CSS styling or JavaScript targeting.
<p id="intro">Welcome to our website!</p>

Class (class)
- A class can be shared by multiple elements.
- Used to group elements for styling or scripting.
<p class="highlight">This is important text.</p>
<p class="highlight">This text is also highlighted.</p>

| Feature      | ID               | Class                        |
| ------------ | ---------------- | ---------------------------- |
| Uniqueness   | Must be unique   | Can be used on many elements |
| CSS selector | `#idName`        | `.className`                 |
| JS usage     | `getElementById` | `getElementsByClassName`     |

Table
- <table>
- <tr> (table row)
- <th> (header cell)
- <td> (data cell)

<table>
   <tr>
      <th>Header</th>
   </tr>
   <tr>
      <td>Data</td>
   </tr>
</table>

Semantic Table Structure 
- <thead> → header section
- <tbody> → body section

<table>
   <thead>
      <tr>
         <th>Header</th>
      </tr>
   </thead>

   <tbody>
      <tr>
         <td>Data</td>
      </tr>
   </tbody>
</table>
